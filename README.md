# Платформа публикации · Godot Developer (тестовые web-сборки) · «Тестовые web-сборки и проверка валидатора»

Тестовое задание на позицию Godot Developer (тестовые web-сборки, стажёр / джун) в проекте «Платформа публикации игровых проектов», Bear Head Studio.
Нужно сделать маленькую игру на Godot 4.4, экспортировать её под Web и проверить валидатор загрузки
демоверсий набором сгенерированных тестовых архивов с манифестом ожидаемых вердиктов.

Задание — в документе
[`Тестовое_задание_Godot_Web_Builds.pdf`](Тестовое_задание_Godot_Web_Builds.pdf).

## Как сдать

Задание — в `Тестовое_задание_Godot_Web_Builds.pdf`, материалы — в этом репозитории: нажмите «Use this template», чтобы создать свою копию. Ссылку на свой публичный репозиторий с решением пришлите на gpetrov@hse.ru. Вопросы — туда же.

## Состав пакета

| Путь | Что это |
|---|---|
| `Тестовое_задание_Godot_Web_Builds.pdf` | задание: задача, входные данные, что сделать, как сдать |
| `starter/game/` | пустой проект Godot 4.4: рендерер Compatibility, действия ввода, пресет Web-экспорта без потоков |
| `starter/UPLOAD_RULES.md` | правила загрузки демоверсии и коды причин отказа |
| `starter/tools/validate_build.py` | эталонный валидатор архива (Python 3.10+, без зависимостей) |
| `starter/archives/manifest.example.csv` | пример формата манифеста тестовых архивов |

## Как начать

Нужны Godot 4.4 с шаблонами экспорта и Python 3.10+.

```bash
cd starter
godot --editor --path game
python3 tools/validate_build.py --help
```

Подробнее о Web-сборке и валидаторе — в `starter/README.md`.
